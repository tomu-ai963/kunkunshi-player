# 工工四プレイヤー

沖縄三線の楽譜「工工四(くんくんしー)」を書き込むと、そのまま音が鳴るWebアプリです。棹の勘所をタップして一音ずつ鳴らすこともできます。

調弦は **本調子**(男弦ド・中弦ファ・女弦ド、C3–F3–C4)に対応しています。

## できること

- 棹の勘所をタップして即発音(16勘所)
- 工工四の文字列を書いて連続再生、テンポ調整
- 譜面は伝統どおり縦組み・右から左に並び、再生中の音が光る

## 記譜の書き方

| 記号 | 意味 |
| --- | --- |
| `合` `乙` `老` `下老` | 男弦の勘所 |
| `四` `上` `中` `尺` `尺♯` `下尺` | 中弦の勘所 |
| `工` `五` `六` `七` `八` `九` | 女弦の勘所 |
| `ー` | 前の音を伸ばす |
| `〇` | 休符 |
| `イ工` のように人偏を付ける | 一オクターブ上 |

`尺#`(半角シャープ)も `尺♯` として読み取ります。空白・改行・読点は区切りとして無視されます。

例:

```
合乙老下老四上中尺工五六七八九ー
九八七六尺中上四下老老乙合ー
```

## 勘所と音階の対応(本調子)

| 弦 | 開放弦 | 人差指 | 中指 | 小指 | | |
| --- | --- | --- | --- | --- | --- | --- |
| 男弦 | 合 ド | 乙 レ | 老 ミ | 下老 ファ | | |
| 中弦 | 四 ファ | 上 ソ | 中 ラ | 尺 シ♭ | 尺♯ シ | 下尺 ド |
| 女弦 | 工 ド | 五 レ | 六 ミ | 七 ファ | 八 ソ | 九 ラ |

工工四は絶対音高ではなく相対的な階名を表す記譜法なので、二揚げや三下げでは同じ文字でも実際の音高が変わります。上表は本調子で四をCに合わせた場合の対応です。

なお、高音域の譜字である `才` `凡` `勺` は資料によって音高の解釈が分かれるため、現時点では未実装です。

## 音源について

現在は Karplus-Strong 合成で撥弦音を近似しています。実際に録音した三線のサンプル音源に差し替えられる構造になっており、`src/KunkunshiPlayer.jsx` 冒頭の `SAMPLE_URLS` に対応を書くだけで切り替わります。

```js
const SAMPLE_URLS = {
  "合": "/sounds/ai.wav",
  "乙": "/sounds/otsu.wav",
  // ...
};
```

未登録の文字は合成音にフォールバックするため、一部だけ差し替えることもできます。録音する場合は16音(合・乙・老・下老・四・上・中・尺・尺♯・下尺・工・五・六・七・八・九)を開放弦から順に単音で録れば揃います。

棹の図に描かれる勘所の位置は平均律から計算した目安です。実際の位置は棹の長さや型によって変わります。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に出力
npm run preview  # ビルド結果の確認
```

## デプロイ

`main` ブランチへの push で GitHub Actions が動き、GitHub Pages に公開されます。リポジトリの Settings → Pages で Source を **GitHub Actions** に設定してください。

リポジトリ名を変えた場合は `vite.config.js` の `base` も合わせて変更します。ユーザーページ(`xxx.github.io`)に置く場合は `base: "/"` にしてください。
